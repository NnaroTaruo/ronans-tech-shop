# Product

## Platform

web

## Stack

User-selected PHP/PDO, MySQL-compatible InnoDB tables, HTML/Tailwind, vanilla JavaScript, PHP admin sessions, LocalStorage cart IDs/quantities, Git/GitHub. XAMPP MariaDB approved for local development.

## Users

Guests browsing and ordering fictional electronics; a demo store admin managing the same catalog and orders; Ronan Antoque learning to maintain and explain the implementation; assessment reviewers evaluating the connected flow.

## Product Purpose

Ronan's Tech Shop is a fictional CubeTech internship assessment store. Success is a complete, correct, explainable guest-purchase/admin-management flow and documented acceptance evidence.

## Capabilities and Constraints

Five teaching stages with a run/understand/confirm pause after each. Ronan confirmed Stage 1 is good, progressed through Stage 2, and requested Stage 3 on November 4, 2026. Stage 3 adds guest checkout, server-owned review, atomic order/stock saving, retry safety and private confirmation. Ronan authorized Stage 4 on November 7, 2026; admin authentication, catalog management, status/cancellation, customer summaries and dashboard are now implemented. Stage 5 was authorized November 11, 2026: final suites/browser interaction checks, desktop/mobile evidence, demo script and submission documentation are prepared. Actual recording/upload, GitHub reviewer access and sending remain Ronan's delivery actions. Progression is not a claim that every manual test passed. No deployment/email sending. No real payments, shipping/tax/discounts, customer accounts or separate customers table. Database prices/stock are authoritative; money uses integer centavos.

## Brand Commitments

Ronan's Tech Shop; Keyboards, Mice, Accessories. User asks for a light background, dark readable text, restrained accent, consistent controls/spacing, clearly fictional data, simple English, and usable customer/admin screens at about 375px and 1280px.

## Evidence on Hand

Seven-page assessment PDF and Ronan's pasted brief. Empty starting workspace. Fictional seed products only; no real customers, reviews, photographs, social accounts, or sales claims. Deadline November 12, 2026 supplied by user.

## Product Principles

- Complete and explain the required flow before adding extras.
- Save order/items/stock atomically; preserve history and prevent duplicate restoration.
- Use database values for business decisions and browser storage only for cart convenience.
- Record actual tests and assistance honestly.

## Accessibility & Inclusion

Responsive desktop/mobile pages, labelled controls, keyboard access, visible focus, useful validation/empty/error feedback.
